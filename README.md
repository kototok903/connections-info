# Connections Info

Wrapper for New York Times Connections with convenient research links per word.

## Stack

- Bun
- TypeScript
- Vite
- React
- Tailwind CSS v4
- shadcn/ui
- Vitest and React Testing Library
- ESLint and Prettier
- Vercel Functions

## Development

Install dependencies and start the Vite client:

```sh
bun install
bun run dev
```

Start the full application with Vercel's local runtime to test locally:

```sh
bun run dev:vercel
```

Run every project check:

```sh
bun run verify
```
