# Connections Info

Quick research links for daily New York Times Connections words.

## Stack

- Bun
- TypeScript
- Vite
- React
- Tailwind CSS v4
- shadcn/ui
- Vitest and React Testing Library
- ESLint and Prettier
- Vercel Functions

## Development

Install dependencies and start the Vite client:

```sh
bun install
bun run dev
```

Start the full application with Vercel's local runtime when the
`/api/connections` function is needed:

```sh
bun run dev:vercel
```

Run every project check:

```sh
bun run verify
```
